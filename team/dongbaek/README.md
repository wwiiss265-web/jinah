# DONGBAEK COFFEE 반응형 홈페이지

## 실행 방법
1. 압축을 해제합니다.
2. `index.html` 파일을 Chrome, Edge 등 브라우저에서 엽니다.
3. 이미지 교체는 `img` 폴더 안의 파일을 같은 이름으로 덮어쓰면 됩니다.

## 폴더 구조
- `index.html` : 메인 페이지 구조
- `menu.html` : 메뉴 페이지 구조
- `brand.html` : 브랜드 소개 페이지
- `character.html` : 캐릭터 소개 페이지
- `css/style.css` : 공통 색상, 레이아웃, 반응형 스타일
- `css/menu.css` : 메뉴 페이지 전용 스타일
- `css/subpages.css` : 브랜드/캐릭터 페이지 전용 스타일
- `js/main.js` : 공통 모바일 메뉴, 검색창, 이벤트 슬라이드, 맨 위로 이동
- `js/menu.js` : 메뉴 카테고리 필터 및 정렬
- `img/` : 홈페이지에서 사용하는 이미지

## 이미지 수정
`img` 폴더 안의 이미지 파일을 수정하거나 교체하세요.
기존 파일명과 확장자를 유지하면 HTML/CSS를 수정하지 않아도 교체됩니다.

## 참고
현재 전달된 시안 이미지를 잘라서 재사용 가능한 이미지 에셋으로 구성했습니다.
검색, 매장찾기, 로그인, 상세 페이지 등은 실제 데이터/API 연결 전의 프론트엔드 시안 기능입니다.

메인 페이지의 상단 메뉴와 빠른 메뉴에서 '메뉴'를 클릭하면 `menu.html`로 이동합니다.

브랜드 소개 메뉴에 마우스를 올리거나 모바일에서 펼치면 '브랜드 소개'와 '캐릭터 소개' 서브메뉴가 표시됩니다.

브랜드 소개 페이지 하단의 긴 브랜드 아이덴티티 이미지는 `img/brand-detail-long.png` 파일입니다. 같은 파일명으로 교체하면 쉽게 수정할 수 있습니다.

캐릭터 소개 페이지 하단의 긴 상세 이미지는 `img/character-detail-long.png`입니다. 같은 파일명으로 교체하면 이미지 내용을 쉽게 수정할 수 있습니다.

메인 페이지 빠른 메뉴 아이콘을 두 번째 참고 이미지 스타일의 동백꽃, 커피잔, 매장, 캘린더, 헤드셋 SVG 아이콘으로 변경했습니다.
